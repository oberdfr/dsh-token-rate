# dsh-token-rate

A DeepSeek Harness plugin that tracks and displays token generation speed in real-time within the conversation header.

## Installation

To install this plugin in your DeepSeek Harness environment:

1. Clone this repository to your local machine:
   git clone https://github.com/oberdfr/dsh-token-rate

2. Open your DeepSeek Harness workspace.

3. Use the plugin manager to install the bundle from the local directory:
   plugin_manager install_bundle C:/path/to/dsh-token-rate

4. Reload the Web GUI with Ctrl+Shift+R.
